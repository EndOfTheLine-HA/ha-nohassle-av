# v0.4.1: documentation only

No code changes. No Hassle AV is now in the default HACS catalog, and the README
that HACS shows now leads with searching for it there. Adding it as a custom
repository stays as a fallback.

- The version number moves to 0.4.1 so the release carries the README.

## Upgrading

Update No Hassle AV in HACS. No restart is needed for the documentation, but Home
Assistant will show the new version after its next restart.
