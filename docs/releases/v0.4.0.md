# v0.4.0: quiet power buttons, and the 0.2.x import is gone

## Power buttons

Pressing Power on or Power off made the source selectors and the Power sensor
unavailable for about 15 seconds and wrote an error to the log, even when the matrix
did what it was told. The Power on and Power off buttons themselves stayed available.

## Cause

Tested on 2026-10-24 by switching the matrix off and on three times each from Home
Assistant, with the status page read every 4 seconds and the Home Assistant log
open beside it:

- After a power command the matrix answered the next status request with something
  that was not a routing report. The integration read that as a failed poll.
- Power on also took the matrix's web server down for 8 to 45 seconds. It still
  answered ping. The poll that follows fails for that long.
- The status page read `none` while the matrix was on and while it was off, so no
  reliable power-state feedback was found over HTTP. The Power sensor stays
  Unknown. The RS-232 port was not tested.

These are observations from one unit, not guarantees about every firmware.

## Changes

- For 60 seconds after the matrix accepts a power command, a failed status read
  keeps the last known data and is logged only at debug level. This applies only if
  the matrix answered the poll before. Outside the window, and for a matrix that was
  already failing, failures work as before.
- **Known limit:** a power command that times out does not open the window, even if
  the matrix received it.
- **Removed:** the import of a matrix set up under the old `monoprice` domain.
  Nothing in this integration now reads, moves or removes another integration's
  config entries, devices or entities. The setup form is a single step.
- A warning in the log if a matrix entry still carries the marker of a 0.3.x import
  that did not finish. See Upgrading.
- The README and AUDIT describe the measured power behavior. The Power sensor
  section no longer calls the sensor a bug.

## Upgrading

Update No Hassle AV in HACS and restart Home Assistant. A matrix whose import to
0.3.x finished keeps its entity IDs, names and history.

Before updating from 0.3.x, check that the matrix and its entities work. 0.4.0
cannot finish an import that was interrupted. If the log says an import may not
have finished, install 0.3.2, restart, then update again.

If you are still on 0.2.x with the old Monoprice entry, install 0.3.2 first, import
the matrix, then update. See the README.
