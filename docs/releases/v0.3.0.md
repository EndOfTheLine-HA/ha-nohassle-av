# v0.3.0: HDMI matrix only, new `nohassle_av` domain

No Hassle AV is now the HDMI matrix only, under its own `nohassle_av` domain, so
it no longer overrides Home Assistant's built-in Monoprice integration and can be
listed in the HACS default catalog.

## Changes

- New domain `nohassle_av`, set up from **Add integration > No Hassle AV**.
- Matrix entries from 0.2.x are moved automatically, keeping entity IDs,
  history, names, area and disabled entities.
- The amplifier is handled by Home Assistant's built-in Monoprice integration
  again; bass, treble and balance live in the temporary
  ha-monoprice-tone-controls repository until Home Assistant includes them.
- Matrix replies are capped at 64 KiB and strictly decoded (from 0.2.4).

## Upgrading

Follow the upgrade steps in the README before restarting. Make a backup first.
