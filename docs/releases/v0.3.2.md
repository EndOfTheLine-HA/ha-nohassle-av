# v0.3.2: documentation only

No code changes. The README that HACS shows is corrected: the amplifier and its
bass, treble and balance controls are now a separate integration,
[No Hassle AV Amplifier](https://github.com/EndOfTheLine-HA/ha-nohassle-amp), and the
temporary ha-monoprice-tone-controls repository that earlier versions pointed at is
retired.

- The "Upgrading from 0.2.x" steps install No Hassle AV Amplifier for an amplifier and
  import both the matrix and the amplifier from their setup menus.
- AUDIT and NOTICE describe the new arrangement.
- The version number moves to 0.3.2 so the release carries these documents.

## Upgrading

Update No Hassle AV in HACS. No restart is needed for the documentation, but Home
Assistant will show the new version after its next restart.
